# SEO Content Gaps

Date: 2026-08-29

## Main Answer

Zebra does **not** need a longer homepage right now. It needs a cleaner technical foundation, better internal link priority, a few accuracy fixes, and more focused localized search pages.

## Homepage Content Audit

| Area | Current State | Gap | Recommendation |
|---|---|---|---|
| Hero | Strong emotional promise: proof for your doctor. | Search entity definition is present but could be sharper above the fold. | Add a short direct definition: "Zebra is an iPhone symptom tracker for POTS, EDS/hEDS, Fibromyalgia, dysautonomia, and invisible illness that turns daily tracking into appointment-ready proof." |
| Condition coverage | Covers POTS, EDS/hEDS, Fibromyalgia, Long COVID, ME/CFS, dysautonomia. | Could dilute homepage if expanded further. | Keep homepage concise; use internal links for deeper condition intent. |
| Doctor proof | Strong core message. | Missing visual proof of the doctor report. | Add a real sample report preview when available. |
| Orthostatic vitals | Strong differentiated feature. | Copy says "lying, sitting, standing" in places. | Align all product copy with current app flow: lying -> standing -> recovery. |
| Privacy/trust | Present and aligned with no separate Zebra health-data server. | Could be more visible near conversion points. | Add short trust line near CTA and search pages, not a large new homepage section. |
| Internal links | Many related links exist. | Priority hierarchy is not obvious enough for search pages. | Link visibly to POTS tracker, doctor report, orthostatic vitals, appointment checklist, invisible illness tracker. |

## Content Gaps Worth Filling

| Gap | Best Format | Why |
|---|---|---|
| Sample doctor report | Product asset + `/doctor-report/` enhancement | Builds trust faster than more copy. |
| Dysautonomia tracker intent | Dedicated search page | Strong overlap with POTS/orthostatic content; currently covered but not owned as a direct search page. |
| Brain fog tracking for appointments | Dedicated search page or article-to-product bridge | High customer language fit and appointment-prep intent. |
| Medication change tracking before appointments | Dedicated article/search bridge | Real appointment-use case; avoid claiming medication management. |
| Salt + hydration tracking for POTS | Dedicated search page | Product-specific and search relevant; should avoid treatment advice. |
| Localized doctor report pages | DE/ES/FR search pages | High intent and likely easier to rank than generic symptom tracker terms. |
| Localized orthostatic test pages | DE/ES/FR, then SV/PT-BR/PL | Product-specific niche with native search variation. |

## Content Not Recommended Now

| Idea | Reason |
|---|---|
| Long homepage medical encyclopedia | Would dilute conversion and overwhelm low-energy users. |
| Dozens of thin condition pages | Risks thin/duplicative content and poor localization quality. |
| AI-search-only pages | Violates Zebra's trust posture and likely adds low-value pages. |
| Aggressive "best app" pages in every language before validation | Comparison claims need native market review and maintenance. |

## Homepage Additions, If Any

Add at most these small pieces:

1. Sharper product definition near the top.
2. Stronger internal link group to the five highest-intent pages.
3. Sample doctor report visual when ready.
4. Corrected orthostatic flow wording.
5. Short trust line near CTAs: patient-entered tracking, not diagnosis or treatment.
